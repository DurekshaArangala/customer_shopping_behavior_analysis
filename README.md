# Customer Shopping Behavior Analysis

## Overview

This project demonstrates an end-to-end data analytics workflow using Python, PostgreSQL, and Power BI. The objective is to analyze customer shopping behavior, identify purchasing patterns, and present actionable business insights through data visualization and reporting.

The project covers the complete analytics pipeline, including data loading, exploratory data analysis (EDA), data cleaning, SQL analysis, dashboard development, and business reporting.

---

## Project Workflow

1. Load the dataset using Python.
2. Perform Exploratory Data Analysis (EDA).
3. Clean and preprocess the data.
4. Import the cleaned dataset into PostgreSQL (pgAdmin 4).
5. Write SQL queries to answer business questions.
6. Build an interactive Power BI dashboard.

---

## Dataset

The dataset contains customer shopping information, including:

* Customer demographics

## How to Run

1. Clone this repository.
2. Install the required Python libraries.
3. Run the Jupyter Notebook for data loading, EDA, and data cleaning.
4. Import the cleaned dataset into PostgreSQL using pgAdmin 4.
5. Execute the SQL queries in the `sql` folder.
6. Open the Power BI dashboard (`.pbix`) to explore the visualizations.
